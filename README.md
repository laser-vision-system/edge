# Edge

Edge Processing Tier μ-com project.

## Details

We are using UV for python version management, package/dependency management, and providing a build toolchain.

You will need to download and install UV yourself.

We are using Python 3.13, UV will handle this for you.

## Setup

Run `uv sync`.

## Start

Run `uv run python -m edge`.

## Tests

Run `uv run pytest`.
